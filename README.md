# 🌙 Dark Mode Custom - Chrome Extension

Uma extensão leve e moderna para Google Chrome que permite aplicar e ajustar o modo escuro em sites individuais com controle de brilho e contraste em tempo real.

## 🚀 Funcionalidades

- **Controle por Domínio:** Ative ou desative o modo escuro especificamente para o site em que está navegando.
- **Ajustes Finos de Exibição:** Sliders de brilho e contraste em tempo real.
- **Persistência de Dados:** Salva suas preferências automaticamente via `chrome.storage`.
- **Interface UI/UX Moderna:** Design escuro refinado com resposta tátil visual.

## 🛠️ Tecnologias Utilizadas

- HTML5 & CSS3
- JavaScript (ES6+)
- Chrome Extension Manifest V3 API (`scripting`, `storage`, `tabs`)
